# AGENTS.md

## 프로젝트 구조

이 프로젝트는 단일 HTML 파일로 구성되어 있으며, 다음과 같은 구조를 가집니다:

```
/랜덤_점심_추천기
├── index.html          # 메인 HTML 파일
└── style.css          # 스타일 시트 (CSS)
```

## 한국어 주석 규칙

1. **주석 작성 방법**: 모든 주석은 한국어로 작성합니다.
2. **주석 위치**: 코드 블록 위 또는 옆에 주석을 배치합니다.
3. **주석 길이**: 가급적이면 간결하게 작성하되, 필요한 정보는 반드시 포함합니다.
4. **주석 형식**:
   - 함수, 클래스 및 주요 로직 설명: `// 함수명: 기능 설명`
   - 복잡한 로직이나 알고리즘 설명: `/* 설명 내용 */`

예시:
```javascript
// 랜덤 점심 메뉴를 추천하는 함수
function 추천점심() {
    // 여기에 추천 로직을 구현합니다
}
```

## 함수 분리 원칙

1. **단일 책임 원칙**: 각 함수는 하나의 기능만 수행해야 합니다.
2. **함수 이름**: 함수의 목적이 명확하게 드러나도록 적절한 이름을 사용합니다.
   - 예: `추천점심()`, `메뉴추출()`, `사용자입력처리()`
3. **재사용성**: 가능하면 여러 곳에서 사용될 수 있도록 함수는 재사용 가능하게 작성합니다.
4. **길이 제한**: 각 함수의 길이는 20-30줄을 넘기지 않도록 합니다. 이는 가독성을 높이고 유지보수를 용이하게 합니다.

## 커밋 규칙

1. **커밋 메시지 형식**: 각 커밋 메시지는 다음 형식을 따릅니다.
   - `[타입] 간단한 설명`
   - 타입: `버그픽스`, `기능추가`, `리팩토링`, `문서화` 등
2. **설명**: 간단한 설명 다음에는 필요시 자세한 설명을 추가할 수 있습니다.
3. **타입 예시**:
   - `기능추가: 랜덤 점심 추천 로직 구현`
   - `버그픽스: 페이지 로드 시 오류 수정`
   - `문서화: AGENTS.md 작성`
4. **커밋 빈도**: 주요 기능이 추가될 때마다 주기적으로 커밋을 수행합니다.

예시:
```
기능추가: 랜덤 점심 추천 로직 구현
- 사용자 입력을 받아서 랜덤으로 점심 메뉴 추천
- 추천된 메뉴는 지역에 따라 다르게 설정
```

이 규칙을 준수하여 협업 및 유지보수 과정에서 일관성을 유지합시다.
