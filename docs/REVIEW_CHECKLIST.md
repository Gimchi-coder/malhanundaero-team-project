- [ ] 평가기준보다 과한 기능을 추가하지 않았는가?

## AI·자동화

- [ ] 입력·출력 계약과 정책 버전이 있는가?
- [ ] n8n workflow의 검증·분기·실패 경로를 재생했는가?
- [ ] 추천은 사람 매칭이 아니라 활동 추천인가?
- [ ] AI 안전판정은 키워드 외 문맥·의도를 고려하는가?
- [ ] 낮은 신뢰도·timeout·malformed 응답을 승인하지 않는가?
- [ ] 수정·재시도·운영자 검토 경로가 있는가?

## 보안·개인정보

- [ ] 브라우저 소스에 비밀 키가 없는가?
